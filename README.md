# WSQ Data Visualisation with Tableau

Course Code: **TGS-2020503177**

This repository contains the public learner courseware and ten self-contained hands-on labs for Tertiary Infotech Academy's two-day WSQ course.

[Course registration and details](https://www.tertiarycourses.com.sg/wsq-data-visualisation-with-tableau.html)

## Contents

- `courseware/` — current PowerPoint/PDF slides, Learner Guide and Lesson Plan.
- `labs/` — ten numbered labs. Every lab contains realistic synthetic Excel data, an editable Tableau workbook definition, a packaged Tableau sample, detailed instructions and an acceptance checklist.
- `LG-Data Visualisation with Tableau.md` — Markdown mirror of the detailed Learner Guide.

## Data and privacy

All organisations, customers, outlets and transactions in the labs are fictional and generated for training. Assessment papers, answer keys, source references, credentials and release tooling are intentionally excluded from this public repository.

## Software

Use Tableau Desktop or Tableau Public. Tableau Public is public by design; do not upload personal, confidential or live operational data.
